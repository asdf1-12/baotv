# 宝视TV

老电视用的轻量直播 + 点播榜单 App，分享测试版。

- 直播：内置仅全国通用央视卫视源（51 台）+ 网络更新 + 自定义 M3U 订阅
- 点播：热播榜 / 电影榜 / 电视剧榜（仅片名），点播源初始为空，需在设置里自己添加 TVBox 式 JSON 订阅
- 全屏播放、开机自启（需电视允许自启动）、节目单尽力匹配、内置浏览器
- 安卓 7.0 以上，2G 内存可用，APK 约 5.9MB

## 安装

U盘拷到电视 / 传文件到电视 → 电视设置开“允许安装未知来源应用” → 点开安装，不用 root。

## 测试版说明（免费分享）

- 免费测试，不收费、不卖会员
- 公开源可能失效，失效就等自动更新或自己换源
- 不含云南 / 贵州地方省内源，不含任何私人节点，不含任何内置点播源
- 没有 VPN 功能，网络走电视系统本身

## 反馈格式

电视品牌 / 安卓版本 / 能不能打开 / 能不能出列表 / 哪个台播不了 / 遥控器有没有问题
